# Project Monitoring System (Academic Capstone & Mini-Project Platform)

An institutional web platform for engineering colleges to manage, monitor, and evaluate student academic projects from allocation to final presentation evaluation.

---

## 1. Technology Stack Architecture

- **Frontend**: React.js 18 + React Router DOM 6 + Lucide Icons + Vite + Academic ERP UI
- **Backend**: Java 25 + Spring Boot 3.5.5 + Spring Security (JWT + BCrypt) + REST APIs + Maven
- **Database**: JPA / Hibernate ORM + MySQL 8.x Dialect (with embedded H2 in-memory test fallback)
- **Authentication**: Predefined Username + Password with BCrypt encryption. Password change requires verifying existing password. No public registration, no OTP, no email/SMS verification.

## 4. How to Run

### Backend (Spring Boot):
```bash
set PATH=C:\Windows\System32;%PATH%
cd backend
.\mvnw spring-boot:run
```
*(Runs on `http://localhost:8080`)*

### Frontend (React + Vite):
```bash
set PATH=C:\Windows\System32;%PATH%
cd frontend
npm install
npm run dev
```
*(Runs on `http://localhost:3000`)*
